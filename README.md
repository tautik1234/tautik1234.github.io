## 🎨 Website Design & Tech Stack

This website is built with a custom editorial design system and modern React architecture:

- **Frontend Framework**: React 18 (SPA)
- **Build Tool & Dev Server**: Vite 5
- **Icons Library**: Lucide React
- **Styling & Theme**: Vanilla CSS custom design system using HSL color tokens (`#0F3040`, `#464858`, `#A56F63`, `#D99B7F`), glassmorphism, and responsive CSS Grid/Flexbox
- **Typography**: Google Fonts (*Cinzel*, *Playfair Display*, *Plus Jakarta Sans*, *Fira Code*)
- **Deployment**: GitHub Pages via automated GitHub Actions workflow (`.github/workflows/deploy.yml`)

## 💻 Local Setup

If you want to run this website locally:

```bash
# Clone the repository
git clone https://github.com/tautik1234/tautik1234.github.io.git

# Install dependencies
npm install

# Start development server
npm run dev
```
